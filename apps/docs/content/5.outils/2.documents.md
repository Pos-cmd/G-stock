G-stock produit trois sortes de PDF, tous avec la même présentation :

| Document | Depuis |
| --- | --- |
| Reçu de vente | La fiche d'une vente : **Reçu PDF**, ou **WhatsApp** pour le format téléphone. |
| Fiche de commande | La fiche d'une commande fournisseur : **Fiche PDF**. |
| Simulation | La fiche d'une simulation : **PDF**. |

Les fichiers sont rangés dans le dossier des documents (par défaut `Documents/G-stock`), dans `Ventes/`, `Commandes/` et `Simulations/`. Produire de nouveau un document remplace l'ancien fichier.

La page **Documents** les liste tous : type, date, emplacement. Chacun s'ouvre, se télécharge, ou renvoie à la vente, la commande ou la simulation d'origine.
